# 風待ち配達局

実在する遠方の風向き・風速をゲームのルールへ取り込む、一人用のターン制配達ゲームです。

## 遊び方

1. 黄色い `✦` の記録を6個すべて集めます。
2. 右上の `⇱` 出口へ行けばクリアです。
3. あなたが1マス動くたび、`☁` の嵐も実際の遠方の風向きに従って動きます。嵐にぶつかると体力が減ります。
4. 「追い風で2マス進む」は各ゲーム2回だけ使えます。

位置情報は使いません。毎回、世界からランダムに選んだ都市の公開天気・風向き・風速を使用します。通信に失敗したときは、日付に基づく代替の風で遊べます。

`main` への push により GitHub Pages に公開されます。
