# 封鎖線

公開されている現実世界の動きを、見えない侵入者の判断へ変換する一人用の非対称ボードゲームです。

## 遊び方

侵入者が 3 つの中継点を起動する前に、捕まえるか、経路を封鎖します。各手番で選べるのは次の 1 つです。

- **移動**: 隣接する地点へ移動する。侵入者と同じ地点に入れば勝利。
- **スキャン**: 任意の地点を調べ、侵入者までの距離を得る。
- **封鎖**: 任意の地点を 2 手番封鎖する。封鎖には回数制限があります。

盤面は上が北、左が西です。ただし、地点名だけを見て判断できます。ゲーム開始時に侵入者の出発地点と最初の痕跡が示されます。

## 現実の取り込み

開始時、以後は 2 手番ごとと 60 秒ごとに世界の脈動を更新します。GitHub Public Events、Hacker News の上位記事、USGS の直近 1 時間の地震情報を集計し、侵入者の移動速度・偽の痕跡・経路変更に反映します。記事の内容をそのままゲームへ出すのではなく、予測しにくい現実の変化をゲーム上の判断材料に変換します。

ネットワークが使えない場合は、ゲームを止めずに代替の脈動で進行します。位置情報は使用しません。
