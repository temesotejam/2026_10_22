# 現実改稿局

現実の空模様と暦を「今日の版」として取り込み、盤面の規則を変える一人用ターン制・戦術パズルゲームです。

## 遊び方

- `✎` が編集官、`✦` が回収する記録片、`◆` が監査官、右下の `⇱` が出口です。
- 三つの記録片を集めてから出口へ到達すると任務成功です。
- 矢印キーまたは画面の矢印で移動し、スペースキーまたは「手番を終える」で敵を動かします。
- 校正カードは一手番に一枚使えます。状況をひっくり返すために使ってください。
- 「遠方の空を読む」を選ぶと、世界の候補都市からランダムに一つを選び、Open-Meteo の現在の天気を今日の版へ反映します。位置情報や個人情報は一切使いません。

## 公開

`main` ブランチへの push で GitHub Pages のデプロイワークフローが実行されます。リポジトリ設定の **Pages** でソースに **GitHub Actions** を選択してください。公開URLは通常 `https://temesotejam.github.io/2026_10_22/` です。

依存関係やビルド工程はありません。ローカルでは `index.html` を静的サーバーで配信して確認できます。
