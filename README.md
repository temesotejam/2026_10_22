# 反証局

公開されている世界の動きを、都市記録を狙う改竄者の行動へ変換する一人用の調査ゲームです。

## 目的

改竄者が 3 つの公的記録を書き換える前に、確保するか、書き換え済みの記録を反証します。手数制限はなく、終了は改竄者の確保か、同時に3件の記録を改竄された時だけです。改竄者は速く移動しますが、記録の書き換えには 2 手の準備が必要です。準備開始時には複数の異常反応が地図に出るため、照合して本物を特定します。

## 行動

- **移動**: 隣の地点へ移動し、証拠を 1 つ持って改竄者と同じ地点に入れば確保。証拠がなければ改竄者は逃げる。
- **照合**: 改竄者の行動後の距離と、次に近い地点を知る。異常反応なら本物の作業を特定し、新しい痕跡なら証拠も得る。
- **隔離**: 一地点を相手の 2 手のあいだ閉鎖し、準備中の改竄者を退避させる。
- **反証**: 証拠を 2 つ使い、書き換え済みの記録を 1 つ取り戻す。

## 現実の取り込み

開始時、以後は 2 手番ごとと 60 秒ごとに GitHub Public Events、Hacker News の上位記事、USGS の直近 1 時間の地震情報を集計します。信号は改竄者の移動速度、迂回、偽の痕跡に反映されます。ネットワークが使えない場合も、代替パルスでゲームは続行します。位置情報は使用しません。
