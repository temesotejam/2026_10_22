# 遠方予報局

現実の遠方天気を毎回取り込み、その観測カードを組み合わせて遊ぶ、一人用デッキ構築パズルです。視覚表現への依存を抑え、`Balatro` の組み合わせ作りと `Slay the Spire` の恒久強化を参考に、明快な得点・提出回数・目標値を中心にしています。

## 遊び方

1. 世界からランダムに選ばれた7都市の公開天気を観測カードとして受け取ります。位置情報は使いません。
2. 1〜5枚を選んで観測式を提出し、章の「残る歪み」を削ります。
3. 同じ空模様の重なり、連続した強度、異なる地域、4種類以上の空模様を同時に作ると高得点です。
4. 各章で4回まで提出できます。歪みをゼロにすると、次の章で使える恒久理論を一つ選べます。
5. 全3章を終えると成功です。引き直しは各章2回までです。

通信できない場合は、日付から作った代替観測でプレイを継続します。
